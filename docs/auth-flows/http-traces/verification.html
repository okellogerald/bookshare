Understanding the verification JSON
"state"
"sent_email" — Already past initialization. Kratos sent email during registration's password step.
"active"
"code" — BookShare uses the code method (6-digit email codes).
hidden method=code
Tells Kratos which verification method on submit.
name: "code" (text)
Visible input for the 6-digit code.
submit method=code
Submit button to validate the code.
submit email=...
Resend action. Clicking re-sends a new code. Auth Portal renders as "Resend code" link.
