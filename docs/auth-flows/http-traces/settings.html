Understanding the combined settings JSON
"state": "show_form"
Settings uses this instead of "choose_method". All fields available immediately.
group: "profile"
Trait fields with pre-filled values. method=profile submits only profile.
group: "password"
Password change fields. method=password submits only password. Ignored by profile page.
Why both groups
Kratos doesn't know BookShare splits settings. Returns full form. Auth Portal filters by group.
Pre-filled values
Every profile field has value from current identity.
